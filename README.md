# STAT CAL

### Statistical Analytics Platform

**STAT CAL** is an interactive statistical analytics platform designed to simplify the process of preparing, exploring, analysing, and interpreting datasets through an integrated analytical workflow.

🌐 **Live Application:** https://stat-cal.vercel.app/

---

## Overview

STAT CAL brings several commonly used statistical analysis workflows into a single application.

The platform is designed around the following workflow:

**Upload → Prepare → Explore → Analyse → Interpret**

It aims to reduce the technical complexity involved in performing statistical analyses while maintaining a structured and transparent analytical process.

---

## Key Features

### 📂 Data Upload

* Dataset upload
* CSV and Excel support
* Automatic dataset inspection
* Variable and data-type identification

### 🧹 Data Preparation

STAT CAL provides data-quality and preparation functionality, including:

* Missing-data handling
* Column-name standardisation
* Text cleaning
* Numeric conversion
* Date standardisation
* Outlier handling
* Data-quality checks

### 📊 Exploratory Data Analysis

Explore datasets through:

* Descriptive statistics
* Summary information
* Distribution analysis
* Data visualisations
* Variable-level exploration

### ⚖️ Group Comparison

Analyse differences between groups using appropriate statistical procedures based on the structure of the data.

### 📈 Regression Analysis

STAT CAL includes:

* Simple Linear Regression
* Multiple Linear Regression
* Logistic Regression

The application is designed to provide an integrated workflow from data preparation through model analysis and interpretation.

### 🔮 Forecasting

STAT CAL provides forecasting functionality for analysing time-dependent data and generating future estimates.

### 📉 Statistical Process Control

The platform includes Statistical Process Control functionality for monitoring process behaviour and identifying potential sources of unusual variation.
